# Marketing-Skripte (Voice + DM)

Rechtssichere Reel-Skripte und ManyChat-DM für TaxDoc Beta. Wording weitgehend unverändert; nur leichte Hinweise zu Links und Disclaimer.

## Dateien

| Datei | Wann nutzen |
|-------|-------------|
| [VIDEO-1-GRENZGAENGER.md](./VIDEO-1-GRENZGAENGER.md) | Grenzgänger-Reel (DE/CH/AT). CTA: Kommentar **GRENZE**. Voiceover → ElevenLabs. |
| [VIDEO-2-MASSE-ABO.md](./VIDEO-2-MASSE-ABO.md) | Massenmarkt / Abo-Vergleich. CTA: Link in Bio oder Kommentar **BETA**. |
| [MANYCHAT-DM-BETA.md](./MANYCHAT-DM-BETA.md) | Auto-DM nach Kommentar. Primär-Link: `/grenze` bei GRENZE; Alt: `/beta-anfrage`. |

## Schnell-Empfehlung

1. **Reel Grenzgänger** → Video 1 + ManyChat auf `GRENZE` → Link `https://taxdoc-beta.onrender.com/grenze`
2. **Reel Beleg-Chaos / Abo** → Video 2 + Bio oder `BETA` → `https://taxdoc-beta.onrender.com/beta-anfrage`
3. **Nicht** die bare Homepage als DM-Ziel – Conversion ist schwächer.

## ElevenLabs

In jeder Datei gibt es einen **kopierfertigen Block** (ohne Markdown-Metadaten). Stimme: Deutsch, ruhig, natürlich; Länge typisch 20–35 Sekunden.

## Generierte Reels (Code)

Die Python-Generatoren in diesem Ordner (`generate_hook_ads.py`, `generate_short_reels.py`) erzeugen Bild-/Videomaterial – sie ersetzen diese Text-Skripte nicht.
