# Organisch vs. Mini-Budget — 14-Tage-Vergleich

**Ziel:** Beide Wege parallel (oder gestaffelt) testen und **Beta-Anfragen** fair vergleichen.  
**Creatives:** dieselben Hook-MP4s (`taxdoc-hook-0X-music.mp4`).  
**Landing:** `/beta-anfrage` — gleiche Seite, nur UTMs unterschiedlich.  
**Voll-Budget-Launch:** `META-14-DAY-LAUNCH.md` (15–30 €/Tag). Dieses Doc = **Spar-Variante** + rein organisch.

---

## Kurz: was du misst

| | Arm A — 100 % organisch | Arm B — Mini-Budget |
|--|-------------------------|---------------------|
| Kanal | IG + FB Posts (LinkedIn optional) | Meta Ads Manager (eigene Kampagne) |
| Geld | 0 € | **5–10 €/Tag** (~70–140 € / 14 Tage) |
| UTM | `utm_medium=organic` | `utm_medium=paid` |
| Primär-KPI | Beta-Anfragen (Admin Hub) | Beta-Anfragen (Admin Hub) |
| Sekundär | Views, 3s-Views, Profilbesuche, Link-Taps | Hook-Rate, Outbound-CTR, CPL |

**Fairness-Regel Nr. 1:** Die organischen Posts von Arm A **nicht** boosten. Arm B läuft nur über **Ads Manager** mit denselben Videos als Ad-Creatives — nicht über „Beitrag boosten“ auf denselben Posts.

## Arm A — 100 % kostenlos (organisch)

1. Alle **5 Hooks** als Reel/Video auf **Instagram + Facebook** posten (LinkedIn optional, gleiche Captions gekürzt).
2. **Kein** Boost, **keine** Ads auf diesen Posts.
3. Bio-Link / Caption-Link auf Landing mit organic-UTMs (unten).
4. Tracking:
   - IG/FB Insights: Views, 3‑Sekunden-Views, Profilbesuche, Link-Taps (falls sichtbar)
   - **Admin Hub → BetaInvites** filtern / zählen nach `utm_medium=organic` (bzw. `utm_content=hook…`)

### Wann starten? Zwei Varianten

| Variante | Ablauf | Wann sinnvoll |
|----------|--------|----------------|
| **B1 — Signal zuerst** | Tage 1–3/4 nur organisch → Top 2–3 Hooks nach Hook-Rate / Saves / Profilbesuche wählen → ab Tag 4 Ads | Empfohlen bei knappen Euro |
| **B2 — Parallel** | Tag 1: alle 5 organisch + Mini-Ads mit 2–3 Favoriten (z. B. Hook 1, 3, 5) | Wenn du schneller CPL sehen willst |

## Fair-Play-Checkliste

- [ ] `utm_medium=organic` vs `utm_medium=paid` — nie vermischen
- [ ] Organische Posts von Arm A **nicht** boosten
- [ ] Arm B = Ads-Manager-Kampagne, **neue** Ad-Creatives (gleiche Dateien, nicht Boost)
- [ ] Gleiche Landing Page `/beta-anfrage`
- [ ] Gleiche Hook-MP4s (Mixkit Piano behalten)
- [ ] Beta-Anfragen nur im **Admin Hub** zählen (Quelle der Wahrheit)
- [ ] 14 Tage durchhalten, bevor du „organisch lohnt nicht“ entscheidest

### Was die Unterschiede typischerweise bedeuten

| Beobachtung | Interpretation |
|-------------|----------------|
| Organic: Views hoch, Leads ≈ 0 | Reichweite ohne Intent — Captions/CTA/Bio-Link prüfen; Paid oft nötig für LP-Traffic |
| Paid: CTR ok, Leads niedrig | Landing / Formular / Message Match — nicht nur Creative |
| Organic-Leads > 0 bei 0 € | Sehr starkes Signal — Paid nur zum Skalieren der Gewinner-Hooks |
| Paid CPL unter X €, organic 0 Leads | Erwartungsgemäß bei kleiner Follower-Basis — Mini-Budget gewinnt auf Leads |
| Beide schwach | Angebot/LP zuerst fixen, bevor mehr Budget |

**Entscheidungshilfe:** Primär immer **Anzahl Beta-Anfragen**. Vanity-Views gewinnen den Vergleich nicht.
