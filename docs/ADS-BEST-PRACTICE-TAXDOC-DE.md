## 1. Was Gewinner-Ads typischerweise machen

Quellen (Prinzipien, keine Scripts): Meta Ads DE/DACH Playbooks, Fintech-CTR-Analysen, Creative-Framework-Reviews (PAS, Listicle, Before/After, Social Proof), Meta Ad Standards zu Finanzprodukten.

### 1.1 Erste 1–2 Sekunden = alles


| Prinzip                     | Praxis für TaxDoc                                                                  |
| --------------------------- | ---------------------------------------------------------------------------------- |
| **Thumb-stop / Hook-Rate**  | Text-Overlay oder Gesicht/Problem-Bild in Sekunde 1 — nicht Logo-allein            |
| **Problem-first (Fintech)** | Relatable Frustration statt Feature-Liste oder Zinssatz-Claims                     |
| **Selbst-Identifikation**   | Zuschauer denkt: „Das bin ich“ (Chaos-Unterlagen, Grenzgänger, Solo-Selbstständig) |
| **Marke früh**              | TaxDoc-Blau + Name in den ersten 3 s sichtbar (nicht erst am Ende)                 |
| **Sound-off ready**         | Große Untertitel; Musik optional (reel-03-music ok)                                |




### 1.2 Strukturen, die oft skalieren

1. **Problem → Agitate → Solution (PAS)** — 60 % Problem/Schmerz, 40 % Produkt (nicht umgedreht).
2. **Before / After** — Chaos → Ordnung (ohne falsche „Rückerstattung €X“-Garantien).
3. **Listicle / Reasons-Why** — „3 Dinge …“ hält Scroll und erklärt Nutzen schnell.
4. **Demo / Peek** — Screen-Recording oder Slide-Flow (Upload → KI → Überblick) wie reel-03.
5. **Social Proof / Trust** — in DE oft länger, konkreter, skeptischer: Beta ehrlich, Disclaimer, kein Guru-Ton.
6. **Offer clarity** — Was ist kostenlos? Was bekomme ich? Was ist *noch* Beta?



### 1.3 CTA & Offer


| Element               | Empfehlung                                                             |
| --------------------- | ---------------------------------------------------------------------- |
| **Ein CTA pro Ad**    | „Mehr erfahren“ / „Jetzt anmelden“ → `/beta-anfrage`                   |
| **Offer klar**        | „Beta kostenlos · kein Abo-Zwang · Feedback willkommen“                |
| **Kein Druck-Fake**   | Keine erfundenen Countdown-Rabatte; knappe Plätze nur wenn wahr        |
| **Landing = Promise** | Ad-Text muss zur Beta-Anfrage-Seite passen (kein Bait-and-Switch)      |
| **DACH-Ton**          | Du ok (wie Brand), konkret, wenig Emoji-Spam, keine leeren Superlative |




### 1.4 DACH-Besonderheiten

- Längere Copy mit Absätzen oft besser als UK/US-Punchline-only.
- Vertrauen > Urgency: Datenschutz, „made in DE“-Signal, ehrliche Grenzen.
- Sie/Du testen als Variable — TaxDoc-Default: **Du**.
- Creative-Diversity: 3–5 Varianten parallel; Hook/Offer vor Format wechseln.

## 3. Targeting (hochlevel, DE)

Interessen/Themen als **Inspiration** — Meta ändert Labels; Special Ad Category ggf. prüfen.


| Segment                         | Idee                                                 | Hinweis                                                  |
| ------------------------------- | ---------------------------------------------------- | -------------------------------------------------------- |
| **Steuererklärung / Steuern**   | Interesse an Steuererklärung, ELSTER, Finanzsoftware | Breit, saisonal stark (Jan–Mai)                          |
| **Selbstständige / Freelancer** | Selbstständigkeit, Freiberufler, Kleinunternehmer    | Pain: Belege ganzjährig                                  |
| **Grenzgänger**                 | Arbeiten in CH/AT/…, Pendler, Auslandseinkommen      | TaxDoc-Differenzierung (Checkliste) — eng, aber relevant |
| **Demografie**                  | DE, 25–55, Deutsch                                   | Altersband testen; 18+ Minimum wo Finanzen greifen       |
| **Lookalikes / Retargeting**    | Website-Besucher `/beta-anfrage`, Video-Viewer 50 %+ | Nach ersten Conversions aufbauen                         |
| **Advantage+**                  | Broad + starke Creatives                             | Creative = Targeting-Hebel                               |


**Nicht:** ZIP-Exclusions wenn Special Ad Category greift; keine sensiblen Finanzdaten in Lead-Forms verlangen.

## 4. Compliance — TaxDoc-Regeln


| Regel                                        | Umsetzen                                                        |
| -------------------------------------------- | --------------------------------------------------------------- |
| ❌ Keine falschen Spar-/Erstattungs-Garantien | Keine „spare garantiert 1.000 €“ / „maximale Rückerstattung“    |
| ❌ Kein Steuerberater-Claim                   | Nie „ersetzt deinen Steuerberater“ / „offizielle Finanzamt-App“ |
| ❌ Keine Fake-ELSTER-Anbindung                | Keine Auto-Abgabe-Versprechen                                   |
| ✅ Ehrliche Beta                              | „Beta“, „Hilfsmittel“, „Schätzung“, „du prüfst selbst“          |
| ✅ Angebot klar                               | Kostenlos in der Beta; späterer Preis getrennt kommunizieren    |
| ✅ Landing match                              | Promise der Ad = Inhalt von `/beta-anfrage`                     |
| ✅ Meta Standards                             | Finanz-/Software-Ads: irreführende Claims vermeiden; LP prüfen  |


Rechtlicher Hintergrund intern: `docs/COMPETITIVE-PARITY-DE.md` (StBerG, Disclaimer).

## 5. Testplan (kurz)

1. **Woche 1:** A + B + C parallel (Traffic oder Conversions → `/beta-anfrage`), gleiches Budget.
2. **Kill/Scale:** Nach ~7 Tagen schwächste 1 Variante pausieren; Hook der Gewinnerin iterieren.
3. **Eine Variable:** z. B. nur Hook-Text oder nur Headline — nicht alles auf einmal.
4. **Refresh:** Alle 4–6 Wochen neues Creative (oder Hook-Slides aus dem Brief).
