## Nur DU am Handy — Schritte 1 bis 8

### 1 — Instagram öffnen & einloggen

1. Instagram-App öffnen  
2. Mit **`@taxdocsteuer`** einloggen (SMS/Code nur du)

### 2 — Business-Konto aktivieren

1. Profil (unten rechts) → Menü (☰) → **Einstellungen und Aktivität**  
2. **Konto-Typ und Tools** → **Auf professionelles Konto umstellen**  
3. Typ: **Business** (oder Creator — beides ok)  
4. Kategorie: z. B. **Software** / **Finanzen** / **Bildung**

### 3 — Profilbild hochladen

1. Profilbild-Datei vom Mac aufs Handy bringen (siehe Tabelle oben)  
2. Instagram → Profil → Profilfoto antippen → **Neues Profilfoto** / **Foto auswählen**  
3. `instagram-profile.png` wählen → fertig (kein Zuschneiden nötig)

### 4 — Anzeigename setzen

1. Profil → **Profil bearbeiten**  
2. **Name** → `TaxDoc` einfügen → Speichern

### 5 — Bio einfügen

1. Weiter in **Profil bearbeiten** → **Bio**  
2. Bio-Text aus dem Copy-Paste-Block oben **1:1** einfügen → Speichern

### 6 — Website-Link setzen

1. Profil bearbeiten → **Links** / Website  
2. Einfügen: `https://taxdoc-beta.onrender.com/beta` → Speichern  
3. Kurz prüfen: Link antippen → Beta-Seite sollte öffnen

### 7 — Reel-Video aufs Handy (ohne CapCut)

1. Fertiges MP4 aus `marketing/reel-01/`, `reel-02/` oder `reel-03/` per AirDrop  
2. Anleitung: jeweiliges **`KOSTENLOS-OHNE-CAPCUT.md`**  
3. CapCut nur optional (`marketing/reel-01/CAPCUT-ANLEITUNG.md`)

### 8 — Reel auf Instagram posten

1. Instagram → **+** → **Reel** → Video aus Galerie wählen  
2. Caption aus dem Copy-Paste-Block oben einfügen (Reel #1, #2 oder #3)  
3. **Teilen**  
4. Hashtag-Block als **ersten Kommentar** → darauf antworten  
5. Details: `marketing/reel-0X/ANLEITUNG-POSTEN.md` (01 / 02 / 03)  
6. Story mit Reel teilen (+ Link-Sticker zur Beta, falls verfügbar)
