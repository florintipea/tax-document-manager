## 1. Executive — was besser machen (2 Min)

Diagnose aus Meta Insights (~5950 Views, **21× 3s**, **0× 1 Min**, 97 % Reels, 99,7 % Non-Follower): Meta kauft billige Impressions. Der Feed scrollt weiter, bevor der Hook greift. Der Algorithmus lernt: „dieses Asset hält niemanden“ → weiter billige Reichweite, keine Signale für Klicks/Leads.

| # | Sofort tun | Warum |
|---|------------|--------|
| 1 | **Ziel wechseln:** Conversions → Event „Lead“ / „BetaInvite“ auf `/beta-anfrage` (Fallback: Landing-Page-Views). Nie „Reichweite“ / „Engagement“ / Boost „mehr Personen“. | Meta optimiert genau das Event — sonst Views ohne Intent. |
| 2 | **Hook in Sekunde 0–1:** Riesen-Text + Problem-Bild *vor* Logo. 3s-View-Rate (Hook-Rate) muss steigen — sonst stirbt alles Downstream. | Andromeda filtert Ads ohne Attention früh raus. |
| 3 | **3–5 konzeptionell verschiedene Hooks** parallel (nicht 5 Caption-Twists derselben Folie). Gewinner iterieren. | Creative Diversity > Micro-Edits. |
| 4 | **Message Match:** Ad-Promise = Headline auf `/beta-anfrage` („Beta kostenlos · Belege sortieren · Hilfsmittel“). | Hoher CTR + 0 Signups = LP/Offer-Problem. |
| 5 | **Vanity killen:** Impressions/Reichweite aus dem Daily-Dashboard streichen. Primär: Cost/Lead, LP-CVR, Outbound-CTR, Hook-Rate. | Sonst Budget für Scroll-Past. |
| 6 | **Reel 04 + Piano behalten**, aber neue Hook-Varianten (siehe §3). Kurze 8–12 s Ads. Sound-off-Captions Pflicht. | User mag Musik; Länge/Hook war das Problem, nicht der Track. |
| 7 | **Pixel + Conversion-API** prüfen: Lead-Event feuert nur bei erfolgreicher Beta-Anfrage. Learning braucht ~50 Events/Woche ideal. | Ohne sauberes Event = Traffic-Optimierung im Verborgenen. |

## 2. Metric-Hierarchie (TaxDoc)

```
PRIMARY (Budget-Entscheidung)
  └─ BetaInvite / Lead (Form Submit auf /beta-anfrage)
       └─ Cost per Lead (CPL)
       └─ Landing-Page Conversion Rate (LP-CVR = Leads ÷ LP-Views)

SECONDARY (Diagnose vor Lead-Volumen)
  └─ Landing Page Views (besser als Link Clicks allein)
  └─ Outbound CTR (Link-Klicks ÷ Impressions)
  └─ Hook-Rate = 3s-Video-Views ÷ Impressions   ← Gate für Creative
  └─ Hold-Rate = ThruPlay oder 15s ÷ 3s-Views   ← Script hält?

IGNORE / NUR KONTEXT
  └─ Reichweite, Impressions, „Views“, Follower-Wachstum, Profile Visits
  └─ 1-Min-Views bei 9–12s Creatives (irrelevant)
```

**Richtwerte Cold Traffic DE (Richtlinien, keine Garantie):**

| Signal | Schwach → kill/iterate | Okay | Stark |
|--------|------------------------|------|-------|
| Hook-Rate (3s/Impr.) | &lt; ~15–20 % | ~25–30 % | 35 %+ |
| Outbound CTR | &lt; 0,5 % | 0,8–1,5 % | 2 %+ |
| LP-CVR (Beta-Form) | &lt; 5 % | 8–15 % | 20 %+ (warm) |

**Diagnose-Matrix:**

| Hook | CTR | LP-CVR | Aktion |
|------|-----|--------|--------|
| ↓ | — | — | Neuer Hook / erster Frame |
| ↑ | ↓ | — | CTA/Offer im Creative schwächer; Copy schärfen |
| ↑ | ↑ | ↓ | Landing Page / Message Match / Form-Friction |
| ↑ | ↑ | ↑ | Scale Budget vorsichtig (+20–30 %/Tag max.) |

- [ ] Placements: Advantage+ Placements ok; Creative **9:16** primär (Reels)

### 4.3 Ad / Creative Rules

- [ ] URL: `https://taxdoc-beta.onrender.com/beta-anfrage` (UTM: `utm_source=meta&utm_medium=paid&utm_campaign=beta_14d&utm_content=hookX`)

- [ ] Meta Pixel + Conversions API auf Beta-Submit

## 5. 14-Tage-Testplan + Kill-Kriterien

### Woche 1 (Tag 1–7) — Creative Screen

| Tag | Aktion |
|-----|--------|
| 1 | Kampagne live: 5 Hooks (oder mind. Reel 04 + 2 neue Hooks) · Conversion/LPV · DE Broad |
| 2–3 | Nur Tracking prüfen (Events, LP mobil). Kein Creative-Kill. |
| 4 | Hook-Rate + Outbound-CTR je Ad; schwächste 1–2 mit klar schlechtem Hook **pausieren** |
| 5–6 | Gewinner-Hook: 1 Iteration (nur erster Frame / Text) |
| 7 | Ranking: Cost/LPV, CTR, frühe Leads |

### Woche 2 (Tag 8–14) — Convert & Decide

| Tag | Aktion |
|-----|--------|
| 8–10 | Budget auf Top-2 Hooks; Message Match LP prüfen wenn CTR↑ CVR↓ |
| 11–12 | Optional Retarget-Set mit Hook 5 (kleines Budget) |
| 13–14 | Report: CPL, # Leads, Hook-Rate Gewinner; nächste 2 Hooks briefen |

### Kill-Kriterien (nach mind. ~1.500–3.000 Impressions **oder** 3+ Tagen Spend je Ad)

| Bedingung | Aktion |
|-----------|--------|
| Hook-Rate klar unter Peer im Account (&lt; ~15–20 %) | **Kill** — neuer Hook |
| CTR okay, **0 Leads** bei ≥ ~40–50 LP-Views | LP/Form fixen, Creative pausieren bis Match |
| Höchster CPL bei ausreichendem Spend vs. Peers | Pause |
| Frequency &gt; ~3,5 + steigender CPM + fallender CTR | Creative refresh |
| Verstoß Claims / Policy-Warnung | Sofort off |

**Scale-Kriterium:** ≥ 1 Lead bei akzeptablem CPL (intern festlegen, z. B. Ziel &lt; 25–40 € in Beta-Phase) **und** Hook-Rate nicht kollabiert → Budget +20–30 %.

## 6. Algorithmus — warum 5950 Views mit 21× 3s scheitern (Plain German)

**Kurz:** Meta hat eure Ads als „billige Tapete“ ausgespielt — viele Augenblicke, fast niemand bleibt drei Sekunden. Ohne Attention gibt’s keine Klicks, ohne Klicks keine Beta-Anfragen, ohne Events lernt das System nichts Nützliches.

1. **Ziel steuert Einkauf.** „Reichweite / Boost / Video Views“ = möglichst viele billige Impressionen. „Conversions / Lead“ = Menschen, die eher absenden. Falsches Ziel → falsche Käufe.

2. **Andromeda / Advantage+ (2025–26):** Creative ist der Targeting-Hebel. Starke Hooks bekommen Distribution; schwache werden leise abgedreht oder nur noch billig gestreut.

3. **Hook-Rate ist die Eintrittskarte.** 21 von ~5950 ≈ **~0,35 % 3s-Rate** — extrem niedrig (gesund oft im Bereich ~20–30 %+ bei Video-Ads). Der Rest des Spots existiert für den Algorithmus praktisch nicht.

4. **97 % Reels + Cold Audience:** Scroll-Tempo maximal. Logo-Intro, langsamer Start, schwacher Text = instant skip. Erste Frame muss „Das bin ich“ triggern.

5. **Vanity-Loop:** Viele Views → Report sieht „erfolgreich“ aus → weiter gleicher Boost → weiter Skip. Break: **andere Metriken + anderes Kampagnenziel + neue Hooks.**

6. **Organic schwach + Ads flach:** Kein Trust-Stack. Paid muss allein tragen: klarer Pain, klarer Offer, klare LP. LinkedIn später; jetzt Meta DE fokussieren.
